# wallet — deferred

The cross-platform OpenFiat wallet (Android, iOS, Linux, macOS, Windows, Web)
is planned as a Flutter application. It has not been scaffolded yet — Flutter
tooling was out of scope for this bootstrap pass (Rust/Python/TypeScript were
prioritized). See the monorepo [ROADMAP.md](../ROADMAP.md).

In the meantime, see [openfiat-specs](https://github.com/OpenFiat-org/openfiat-specs)
for the protocol this wallet will implement, and
[`../../openfiat-sdks`](https://github.com/OpenFiat-org/openfiat-sdks) for the
SDKs it is expected to consume (a Dart/Flutter SDK would need to be added
there first).
